# REST API Specification (Final Release)

This document details every REST endpoint provided by the **FastAPI Backend** of the City Health Vaccination Outreach Planner.

OpenAPI / Swagger interactive documentation is generated automatically by FastAPI at:  
`http://127.0.0.1:8000/docs`

---

## 🔒 Authentication Endpoints

### 1. User Login
- **HTTP Method**: `POST`
- **Route**: `/api/auth/login`
- **Authentication**: None (Public)
- **Request Body**:
  ```json
  {
    "username": "admin",
    "password": "AdminPass123!"
  }
  ```
- **Response Payload** (`TokenResponse`):
  ```json
  {
    "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "token_type": "bearer",
    "user_id": "usr-admin-001",
    "username": "admin",
    "role": "ADMIN",
    "full_name": "System Administrator"
  }
  ```
- **Errors**: `HTTP 401 Unauthorized` (Invalid credentials), `HTTP 403 Forbidden` (Inactive account).

### 2. Get Authenticated User Profile
- **HTTP Method**: `GET`
- **Route**: `/api/auth/me`
- **Authentication**: Bearer Token required
- **Response Payload**: `UserResponse` object with user_id, username, role, full_name, is_active.

## 🏙️ Area & GIS Endpoints

### 3. List All City Zones
- **HTTP Method**: `GET`
- **Route**: `/api/areas`
- **Authentication**: Bearer Token required
- **Response Payload**: Array of `AreaDetail` objects.

### 4. Get City Zones GeoJSON
- **HTTP Method**: `GET`
- **Route**: `/api/areas/geojson`
- **Authentication**: None / Public
- **Response Payload**: GeoJSON FeatureCollection with polygon boundaries and live risk/coverage properties.

### 5. Get Single Zone Detail
- **HTTP Method**: `GET`
- **Route**: `/api/areas/{area_id}`
- **Authentication**: Bearer Token required
- **Errors**: `HTTP 404 Not Found`.

---

## 🎯 Outreach Planner & Optimizer Endpoints

### 6. Generate Outreach Plan (Integer Linear Program)
- **HTTP Method**: `POST`
- **Route**: `/api/planner/generate`
- **Authentication**: Bearer Token required (`ADMIN` or `CLINICIAN`)
- **Request Body**: `PlanRequest` JSON
- **Response Payload**: Array of `RecommendationResponse` objects generated by the PuLP ILP solver.

### 7. Objective Comparison Matrix
- **HTTP Method**: `POST`
- **Route**: `/api/planner/compare`
- **Authentication**: Bearer Token required
- **Response Payload**: Array of `PlanComparisonResponse` objects.

---

## ✍️ Governance & Review Endpoints

### 8. Submit Human Review Decision
- **HTTP Method**: `POST`
- **Route**: `/api/reviews/approve`
- **Authentication**: Bearer Token required (`ADMIN` or `CLINICIAN`)
- **Role Permissions**:
  - `CLINICIAN`: Can submit `ACCEPTED`, `MODIFIED`, `REJECTED`.
  - `ADMIN`: Full permissions including `OVERRIDDEN`.
- **Request Body**: `ReviewRequest` JSON
- **Errors**:
  - `HTTP 401 Unauthorized`: Token missing/invalid.
  - `HTTP 403 Forbidden`: Clinician attempting `OVERRIDDEN`.
  - `HTTP 404 Not Found`: Recommendation ID not found.
  - `HTTP 409 Conflict`: Concurrent review collision or recommendation already finalized.
  - `HTTP 422 Unprocessable Entity`: Invalid capacity/travel bounds.

### 9. Retrieve Audit Trail Log
- **HTTP Method**: `GET`
- **Route**: `/api/reviews/audit-trail`
- **Authentication**: Bearer Token required

### 10. List Recommendations
- **HTTP Method**: `GET`
- **Route**: `/api/reviews/recommendations`
- **Authentication**: Bearer Token required

## 📈 Forecasting & Evaluation Endpoints

### 11. Multi-Period Demand & Risk Forecast
- **HTTP Method**: `GET`
- **Route**: `/api/forecast`
- **Authentication**: Bearer Token required
- **Query Params**: `area_id` (optional)
- **Response Payload**: Array of forecast objects containing SES projections, trends, and confidence scores.

### 12. Compute Evaluation Metrics
- **HTTP Method**: `GET`
- **Route**: `/api/eval/metrics`
- **Authentication**: Bearer Token required

### 13. Get Error Analysis Scenarios
- **HTTP Method**: `GET`
- **Route**: `/api/eval/error-analysis`
- **Authentication**: Bearer Token required

### 15. Readiness Check

- **Route**: `/readiness`
